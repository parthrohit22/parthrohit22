## What this GitHub shows

The pinned repositories are the work. This profile is the context behind it.

I care about systems that remain understandable after they ship: where a fact came from, who owns the state, what happens when a dependency fails and how another engineer can reproduce or challenge the result.

| Engineering concern | What I look for |
| --- | --- |
| **AI behaviour** | Grounded context, citations where evidence matters and clear output boundaries |
| **Backend systems** | Typed contracts, explicit ownership, durable state and defensible data decisions |
| **Reliability** | Failure paths, controlled errors, tests that exercise more than the happy path |
| **Trust** | Provenance, audit history, deterministic checks and honest capability limits |
| **Delivery** | Readable repositories, meaningful pull requests, CI, review gates and documentation |
